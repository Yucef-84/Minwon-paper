# 민원지 작성기 v1.0.2

압축을 푼 뒤 `index.html`을 직접 열어 사용합니다. 인터넷 연결 없이 HWPX를 생성할 수 있습니다.

지원 환경은 Windows 10/11의 최신 Chrome·Edge와 최신 Firefox이며, 최소 화면 크기는 1024×768입니다. Safari와 모바일은 지원하지 않습니다. HWPX는 Windows 한컴오피스 2024 최신 패치에서 인수 검증합니다.

`인쇄 / PDF 저장`은 브라우저 인쇄 창을 열어 PDF 저장을 선택합니다. HWPX에는 현재 레이아웃에서 보이는 지도와 사진만 포함됩니다.
